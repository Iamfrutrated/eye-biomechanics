Coordinates and transfer rule

+x points right from the source toward the lens; +y points upward. Angles are measured from +x, counterclockwise positive. At x = 1.00 m, the model applies θout = θin − y/f. Paths are drawn with tan(θ); f > 0 is converging and f < 0 is diverging.

Equation, units, and sign convention

1/f = 1/do + 1/di

All calculations use metres. The displayed board is fixed at do = +6.00 m. Distance is measured from the thin lens along the light path: do is positive for this real object, while di and f are positive for a real image beyond the lens.

Neutral uses a +24.0 mm reference plane. Farsighted levels place the calculated image beyond that plane; nearsighted levels place it before the plane. Each level changes di by 0.6 mm. Blur is a qualitative display cue, not a prediction of individual vision.
